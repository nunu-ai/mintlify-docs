---
title: 'Get Job Details'
openapi: 'GET /jobs/{jobId}'
noindex: true
---

<Info>
  **Permission Required**: `project:read-runs`
</Info>

Retrieve details for a specific job, including associated runs.

## Path Parameters

<ParamField path="jobId" type="string" required>
  The job ID (UUID)
</ParamField>

## Response

The response uses the same Job object described in [List Jobs](/api-reference/jobs/list-jobs).

<RequestExample>
```bash cURL
curl -X GET "https://nunu.ai/api/v1/jobs/f80f6230-3a4f-431a-9d55-d11b867fed4e" \
  -H "X-Api-Key: YOUR_API_TOKEN"
```
</RequestExample>
